# Smart Ring — Backend

Бэкенд-сервис проекта Smart Ring (учебный проект БГТУ).

**Стек:** Java 21, Spring Boot, Maven, Docker.

В проекте два способа запуска:

- **Локальная разработка**: для повседневной работы, запуск из IntelliJ IDEA.
- **Запуск через Docker**: так приложение работает на сервере. Нужен для проверки сборки.

---

## Локальная разработка (первый запуск)

### Шаг 1. Установите IntelliJ IDEA

Скачайте с https://www.jetbrains.com/idea/download и установите. Подойдёт и бесплатная Community-версия.

### Шаг 2. Откройте проект

1. Склонируйте репозиторий (или используйте уже склонированный).
2. В IDEA: **File → Open**, выберите папку проекта (ту, где лежит файл `pom.xml`).
3. Если IDEA спросит «Trust Project», нажмите **Trust Project**.

### Шаг 3. Дождитесь загрузки зависимостей

Внизу справа появится индикатор загрузки: IDEA сама скачает зависимости через Maven. Подождите, пока он исчезнет (при первом открытии это может занять несколько минут). Ничего устанавливать отдельно не нужно.

### Шаг 4. Выберите JDK 21

1. Откройте **File → Project Structure → Project**.
2. В поле **SDK** выберите Java 21. Если его нет в списке: **Add SDK → Download JDK**, версия **21**, вендор любой (например, Eclipse Temurin), нажмите **Download**.
3. Нажмите **OK**.

### Шаг 5. Найдите главный класс

Дважды нажмите `Shift`, введите `SmartRingApplication` и откройте найденный класс.

### Шаг 6. Запустите приложение

Нажмите зелёный треугольник слева от строки с `public static void main` (или рядом с названием класса) и выберите **Run 'SmartRingApplication'**.

Внизу откроется окно **Run** с логами. Приложение запущено, когда в логах появилась строка вида:

```
Started SmartRingApplication in 1.3 seconds
```

### Шаг 7. Проверьте результат

Откройте в браузере:

- http://localhost:8080/api/hello: должен показать `Hello from backend`.
- http://localhost:8080/actuator/health: должен показать статус `UP`.

### Шаг 8. Остановите приложение

Нажмите красный квадрат в окне **Run**.

### Если что-то не работает

- **Port 8080 was already in use**: порт занят. Скорее всего, запущен контейнер из раздела про Docker. Остановите его (`Ctrl+C` в его терминале) и запустите приложение снова.
- **Красные ошибки в коде сразу после открытия**: проект ещё загружается, подождите окончания индикатора. Если не помогло, откройте вкладку **Maven** справа и нажмите кнопку **Reload All Maven Projects**.
- **Ошибка про версию Java**: вернитесь к шагу 4 и проверьте, что выбран JDK 21.

### Дальше в повседневной работе

После первого запуска достаточно нажимать зелёный треугольник или `Shift+F10`. Если вы изменили `pom.xml`, нажмите на появившуюся кнопку **Load Maven Changes** (значок «m» с обновлением).

## Запуск через Docker (как на сервере)

Так приложение запускается на стенде. JDK и Maven для этого устанавливать не нужно, всё соберётся внутри Docker. Команды можно вводить в терминале IDEA (вкладка **Terminal** внизу) или в любом другом.

### Шаг 1. Проверьте, установлен ли Docker

```bash
docker --version
```

Если команда вывела версию, переходите к шагу 3.

### Шаг 2. Установите Docker (если не установлен)

Скачайте и установите [Docker Desktop](https://www.docker.com/products/docker-desktop/), затем запустите его и дождитесь, пока значок в строке меню покажет, что Docker работает.

### Шаг 3. Проверьте, что Docker запущен

```bash
docker run --rm hello-world
```

Должно вывести приветственное сообщение `Hello from Docker!`. Если пишет, что не может подключиться к демону, запустите Docker Desktop.

### Шаг 4. Откройте папку проекта в терминале

Перейдите в корневую папку репозитория, где лежит файл `Dockerfile`. В терминале IDEA это уже сделано автоматически.

### Шаг 5. Соберите образ

```bash
docker build -t backend:local .
```

> Первая сборка долгая (около 3 минут): скачиваются базовые образы и зависимости Maven. Повторные сборки быстрее благодаря кэшу.

В конце не должно быть строк с `ERROR`.

### Шаг 6. Запустите контейнер

```bash
docker run --rm -p 8080:8080 backend:local
```

Если приложение уже запущено из IDEA, сначала остановите его, иначе порт 8080 будет занят.

### Шаг 7. Проверьте результат

Откройте в браузере:

- http://localhost:8080/api/hello: должен показать `Hello from backend`.
- http://localhost:8080/actuator/health: должен показать статус `UP`.

### Шаг 8. Остановите контейнер

`Ctrl+C` в терминале, где он запущен.
